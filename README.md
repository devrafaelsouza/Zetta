# 🎬 Zetta

> Sistema de gerenciamento de conteúdos desenvolvido em Java.

## 📖 Sobre o projeto

O **Zetta** é um projeto desenvolvido em Java com o objetivo de praticar programação e aplicar, na prática, conceitos de desenvolvimento de sistemas.

O sistema simula uma plataforma de conteúdos digitais, permitindo que os usuários naveguem pelo catálogo, pesquisem conteúdos, organizem suas listas pessoais e consultem seu histórico.

O projeto está em constante desenvolvimento, recebendo novas funcionalidades, melhorias e implementações conforme a evolução dos conhecimentos em programação.

## 🚀 Funcionalidades

- 👤 Cadastro e login de usuários

- 🔎 Pesquisa de conteúdos

- 🔍 Pesquisa combinada com filtros
- 📋 Adição de conteúdos à lista pessoal
- ❌ Remoção de conteúdos da lista
- 📚 Histórico de conteúdos acessados
- 🧹 Limpeza do histórico
- ℹ️ Exibição das informações dos conteúdos
- 💾 Persistência de dados em arquivos locais
- 🔄 Recuperação automática do catálogo e dos usuários ao iniciar o sistema

## 💾 Persistência de dados

Uma das etapas importantes do desenvolvimento do Zetta foi a implementação da persistência de dados utilizando a serialização de objetos do Java.

Com essa funcionalidade, o sistema consegue salvar informações em arquivos locais e recuperá-las quando é executado novamente.

Os arquivos utilizados são:

- `catalogo.dat`: armazenamento dos dados do catálogo de conteúdos.
- `usuarios.dat`: armazenamento dos dados dos usuários.

A implementação utiliza recursos como `Serializable`, `ObjectOutputStream` e `ObjectInputStream` para realizar a gravação e a leitura dos objetos.

### Testes realizados

- Inicialização do sistema com os arquivos de dados.
- Criação dos arquivos de persistência.
- Recuperação do catálogo após reiniciar o programa.
- Recuperação dos usuários salvos.
- Login com um usuário cadastrado anteriormente.

Os testes realizados confirmaram o funcionamento básico da persistência de dados implementada no projeto.
