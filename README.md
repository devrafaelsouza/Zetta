# 🎬 Zetta

> Sistema de gerenciamento de conteúdos desenvolvido em Java.

## 📖 Sobre o projeto

O **Zetta** é um projeto desenvolvido em Java com o objetivo de praticar programação e aplicar, na prática, conceitos de desenvolvimento de sistemas.

O projeto simula uma plataforma de conteúdos, permitindo que o usuário navegue pelo catálogo, pesquise conteúdos, adicione itens à sua lista e acompanhe seu histórico.

O projeto está em desenvolvimento e recebe novas funcionalidades e melhorias conforme o aprendizado.

## 🚀 Funcionalidades

* 👤 Cadastro e login de usuário
* 🎬 Catálogo de conteúdos
* 🔎 Pesquisa de conteúdos
* 🏷️ Pesquisa por gênero
* 📋 Minha lista
* ❌ Remoção de conteúdos da lista
* 📚 Histórico de conteúdos assistidos
* 🧹 Limpeza do histórico
* ℹ️ Exibição das informações dos conteúdos
